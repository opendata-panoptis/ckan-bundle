# Οδηγός 1: Διαχείριση Κεντρικών Διαχειριστών (Sysadmin)

## Τι είναι ο Κεντρικός Διαχειριστής

Ο **Κεντρικός Διαχειριστής (Sysadmin)** έχει πλήρη πρόσβαση σε ολόκληρη την πλατφόρμα. Μπορεί να:

- Δημιουργεί και να διαχειρίζεται Οργανισμούς
- Προσθέτει και να αφαιρεί μέλη από οποιονδήποτε Οργανισμό
- Προάγει άλλους χρήστες σε Κεντρικούς Διαχειριστές
- Έχει πρόσβαση σε όλα τα σύνολα δεδομένων (δημόσια και ιδιωτικά)
- Χρησιμοποιεί τα εργαλεία μαζικής διαχείρισης (User management)

Ξεκινάτε με **έναν demo λογαριασμό** που είναι ήδη Κεντρικός Διαχειριστής. Με αυτόν μπορείτε να προάγετε και άλλους χρήστες.

### Πού βλέπω τους τρέχοντες Κεντρικούς Διαχειριστές;

Στη σελίδα **`/ckan-admin`** εμφανίζονται οι τρέχοντες Κεντρικοί Διαχειριστές του συστήματος. Μπορείτε να φτάσετε εκεί:
- Από το πάνω μενού πατώντας το εικονίδιο **Sysadmin** (σφυρί) → **Ρυθμίσεις (Config)**
- Ή μέσα από τη σελίδα **Διαχείριση Χρηστών (User management)**, όπου υπάρχει κάρτα που σας παραπέμπει

---

## Σημαντικό: Χρησιμοποιείτε email στα CSV

Το **username** κάθε χρήστη αποδίδεται **αυτόματα από το σύστημα** κατά την πρώτη σύνδεσή του. Δεν είναι εύκολο να το γνωρίζετε εκ των προτέρων.

Αντίθετα, το **email** είναι γνωστό και μοναδικό για κάθε χρήστη.

**Σε όλα τα CSV αρχεία που ετοιμάζετε, χρησιμοποιείτε τη στήλη `email`.**

---

## Ροή Α: Προαγωγή χρηστών σε Κεντρικούς Διαχειριστές

Αυτή η ροή σας επιτρέπει να ορίσετε έναν ή περισσότερους χρήστες ως Κεντρικούς Διαχειριστές, ανεβάζοντας ένα αρχείο CSV.

### Βήμα 1: Ετοιμάστε το αρχείο CSV

Δημιουργήστε ένα αρχείο CSV με μία στήλη: `email`. Κάθε γραμμή αντιστοιχεί σε έναν χρήστη που θέλετε να γίνει Κεντρικός Διαχειριστής.

**Παράδειγμα αρχείου `sysadmins.csv`:**

```
email
maria.papadopoulou@dimos.gr
kostas.nikolaou@dimos.gr
eleni.georgiou@dimos.gr
```

**Συμβουλή**: Μην ξεκινάτε το CSV από το μηδέν. Στο πλαϊνό πάνελ κάθε εργαλείου υπάρχει σύνδεσμος για **λήψη προτύπου CSV** με τις σωστές επικεφαλίδες. Κατεβάστε το πρότυπο και συμπληρώστε τα δεδομένα σας.

### Βήμα 2: Συνδεθείτε στην πλατφόρμα

Συνδεθείτε με τον λογαριασμό demo που είναι ήδη Κεντρικός Διαχειριστής.

### Βήμα 3: Πλοηγηθείτε στο εργαλείο

1. Από το πάνω μενού, πατήστε το εικονίδιο **Sysadmin** (σφυρί)
2. Στο μενού διαχείρισης, πατήστε **Διαχείριση Χρηστών (User management)**
3. Στην κάρτα **"Μαζική προαγωγή σε διαχειριστές συστήματος(Bulk sysadmin promotion)"**, πατήστε **Άνοιγμα(Open)**

Εναλλακτικά, μπορείτε να πλοηγηθείτε απευθείας στη διεύθυνση:
`/ckan-admin/users/sysadmin-promote`

### Βήμα 4: Ανεβάστε το CSV

1. Πατήστε **"Επιλογή αρχείου (Choose file)"** και επιλέξτε το αρχείο CSV που ετοιμάσατε
2. Αφήστε απενεργοποιημένο το **"Αφαίρεση sysadmin από χρήστες που δεν είναι στο CSV (Remove sysadmin from users not in CSV)"** (θα το εξηγήσουμε στη Ροή Β)
3. Πατήστε **"Προεπισκόπηση (Preview)"**

### Βήμα 5: Ελέγξτε την προεπισκόπηση

Η πλατφόρμα θα σας δείξει ένα **σχέδιο αλλαγών** χωρίς να εφαρμόσει τίποτα ακόμα. Θα δείτε:

| Κατηγορία | Τι σημαίνει |
| --- | --- |
| **Would be promoted** | Χρήστες που θα γίνουν Κεντρικοί Διαχειριστές |
| **Already sysadmin** | Χρήστες που είναι ήδη Κεντρικοί Διαχειριστές (δεν αλλάζει τίποτα) |
| **Would create (new pending users)** | Χρήστες που δεν υπάρχουν ακόμα στο σύστημα — θα δημιουργηθούν ως εκκρεμείς (pending) με δικαιώματα Κεντρικού Διαχειριστή. Θα ενεργοποιηθούν αυτόματα κατά την πρώτη τους σύνδεση. |
| **Not found** | Καταχωρήσεις που δεν μπόρεσαν να αντιστοιχιστούν σε ενεργό χρήστη (π.χ. δόθηκε μόνο username χωρίς email και δεν βρέθηκε, ή ο χρήστης είναι διαγραμμένος). **Σημείωση**: αν δοθεί email που δεν βρέθηκε, ο χρήστης δεν εμφανίζεται εδώ αλλά στο "Would create" παραπάνω. |

Ελέγξτε προσεκτικά τα αποτελέσματα.

### Βήμα 6: Εφαρμόστε τις αλλαγές

Αν είστε ικανοποιημένοι με την προεπισκόπηση, πατήστε **"Εφαρμογή αλλαγών (Apply changes)"** (κόκκινο κουμπί).

Η πλατφόρμα θα εμφανίσει σύνοψη: πόσοι προήχθησαν, πόσοι δημιουργήθηκαν, πόσα σφάλματα υπήρξαν.

### Βήμα 7: Κατεβάστε τα αποτελέσματα (προαιρετικό)

Πατήστε **"Λήψη αποτελεσμάτων CSV (Download results CSV)"** για να κατεβάσετε αναλυτική αναφορά σε αρχείο CSV. Χρήσιμο για αρχειοθέτηση.

## Ροή Β: Αφαίρεση δικαιωμάτων Κεντρικού Διαχειριστή

Αν θέλετε να **αφαιρέσετε** τα δικαιώματα Κεντρικού Διαχειριστή από κάποιον χρήστη, η λογική είναι η εξής:

**Ετοιμάζετε ένα CSV με τους χρήστες που ΘΕΛΕΤΕ να παραμείνουν Κεντρικοί Διαχειριστές**, και ενεργοποιείτε την επιλογή "Remove missing". Όποιος δεν είναι στο CSV, θα υποβαθμιστεί.

### Βήμα 1: Ετοιμάστε το αρχείο CSV

Φτιάξτε ένα CSV με τα email **μόνο των χρηστών που θέλετε να παραμείνουν** Κεντρικοί Διαχειριστές.

**Παράδειγμα — Θέλετε να παραμείνουν μόνο δύο Κεντρικοί Διαχειριστές:**

```
email
maria.papadopoulou@dimos.gr
kostas.nikolaou@dimos.gr
```

Οποιοσδήποτε άλλος Κεντρικός Διαχειριστής (εκτός από εσάς και τους προστατευμένους λογαριασμούς) θα υποβαθμιστεί.

### Βήμα 2: Ανεβάστε το CSV με την επιλογή αφαίρεσης

1. Πλοηγηθείτε στο **Sysadmin → Διαχείριση Χρηστών (User management) → Μαζική προαγωγή σε διαχειριστές (Bulk sysadmin promotion) → Άνοιγμα (Open)**
2. Επιλέξτε το αρχείο CSV
3. **Ενεργοποιήστε** το checkbox **"Αφαίρεση sysadmin από χρήστες που δεν είναι στο CSV (Remove sysadmin from users not in CSV)"**
4. Πατήστε **"Προεπισκόπηση (Preview)"**

### Βήμα 3: Ελέγξτε την προεπισκόπηση

Εκτός από τις κατηγορίες της Ροής Α, τώρα θα δείτε και:

| Κατηγορία | Τι σημαίνει |
| --- | --- |
| **Would be demoted** | Κεντρικοί Διαχειριστές που **δεν** είναι στο CSV — θα χάσουν τα δικαιώματά τους |
| **Protected (skipped)** | Λογαριασμοί που προστατεύονται και **δεν μπορούν** να υποβαθμιστούν (βλ. παρακάτω) |

**Ελέγξτε προσεκτικά τη λίστα "Would be demoted"** πριν προχωρήσετε.

### Βήμα 4: Εφαρμόστε τις αλλαγές

Αν είστε σίγουροι, πατήστε **"Εφαρμογή αλλαγών (Apply changes)"**.

---

## Κανόνες ασφαλείας

Η πλατφόρμα εφαρμόζει αυτόματα κανόνες ασφαλείας που **δεν μπορείτε να παρακάμψετε**:

1. **Ο λογαριασμός με τον οποίο είστε συνδεδεμένοι δεν μπορεί ποτέ να υποβαθμιστεί.** Δεν μπορείτε να αφαιρέσετε τα δικαιώματα Κεντρικού Διαχειριστή από τον εαυτό σας.

2. **Προστατευμένοι λογαριασμοί** (αν έχουν οριστεί από τον τεχνικό διαχειριστή) δεν υποβαθμίζονται ποτέ, ακόμα κι αν δεν περιλαμβάνονται στο CSV.

3. **Η προεπισκόπηση (Preview) δεν κάνει καμία αλλαγή.** Οι αλλαγές εφαρμόζονται μόνο όταν πατήσετε "Εφαρμογή αλλαγών (Apply changes)".

4. **Τα αποτελέσματα αποθηκεύονται προσωρινά** (30 λεπτά). Μετά από αυτό το διάστημα, θα πρέπει να ξαναεκτελέσετε τη διαδικασία αν θέλετε να τα δείτε.

---

## Παράδειγμα: Πλήρης ροή από την αρχή

**Σενάριο**: Θέλετε η Μαρία και ο Κώστας να είναι Κεντρικοί Διαχειριστές, και η Ελένη που ήταν παλιά Κεντρική Διαχειρίστρια να μην είναι πλέον.

1. Φτιάξτε το αρχείο `sysadmins.csv`:
   ```
   email
   maria.papadopoulou@dimos.gr
   kostas.nikolaou@dimos.gr
   ```

2. Συνδεθείτε με τον demo sysadmin λογαριασμό

3. Πηγαίνετε: **Sysadmin → Διαχείριση Χρηστών (User management) → Μαζική προαγωγή σε διαχειριστές (Bulk sysadmin promotion) → Άνοιγμα (Open)**

4. Ανεβάστε το CSV, ενεργοποιήστε **"Αφαίρεση sysadmin από χρήστες που δεν είναι στο CSV (Remove sysadmin from users not in CSV)"**, πατήστε **"Προεπισκόπηση (Preview)"**

5. Στην προεπισκόπηση θα δείτε:
   - **Would be promoted**: Μαρία, Κώστας (αν δεν ήταν ήδη sysadmin)
   - **Already sysadmin**: Μαρία ή Κώστας (αν ήταν ήδη sysadmin)
   - **Would be demoted**: Ελένη
   - **Protected**: Ο demo λογαριασμός σας (δεν μπορεί να υποβαθμιστεί)

6. Αν όλα είναι σωστά, πατήστε **"Εφαρμογή αλλαγών (Apply changes)"**

7. Κατεβάστε τα αποτελέσματα με **"Λήψη αποτελεσμάτων CSV (Download results CSV)"** για αρχείο
