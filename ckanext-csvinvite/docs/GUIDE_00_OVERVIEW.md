# Οδηγός Διαχείρισης Πλατφόρμας Δεδομένων — Γενική Επισκόπηση

## Τι είναι η πλατφόρμα δεδομένων

Η πλατφόρμα δεδομένων είναι ένα σύστημα διαχείρισης ανοιχτών δεδομένων. Μέσα από αυτή μπορείτε να δημοσιεύετε, να οργανώνετε και να μοιράζεστε σύνολα δεδομένων (datasets) με τους πολίτες και τις υπηρεσίες σας.

Η πλατφόρμα υποστηρίζει **μαζικές λειτουργίες μέσω αρχείων CSV**, ώστε να μπορείτε να διαχειρίζεστε πολλούς χρήστες ταυτόχρονα χωρίς να χρειάζεται να τους προσθέτετε έναν-έναν.

---

## Βασικές έννοιες

### Τι είναι ο Οργανισμός

Ο **Οργανισμός** είναι η βασική μονάδα ομαδοποίησης στην πλατφόρμα. Κάθε σύνολο δεδομένων (dataset) ανήκει σε έναν οργανισμό. Για παράδειγμα, μπορεί να δημιουργήσετε ξεχωριστούς οργανισμούς για κάθε Διεύθυνση ή Τμήμα του Δήμου.

### Ρόλοι χρηστών

Στην πλατφόρμα υπάρχουν δύο επίπεδα ρόλων:

#### Επίπεδο πλατφόρμας

| Ρόλος | Περιγραφή |
| --- | --- |
| **Κεντρικός Διαχειριστής (Sysadmin)** | Έχει πλήρη πρόσβαση σε ολόκληρη την πλατφόρμα. Μπορεί να δημιουργεί οργανισμούς, να διαχειρίζεται χρήστες, να προάγει άλλους σε Κεντρικούς Διαχειριστές και να έχει πρόσβαση σε όλα τα σύνολα δεδομένων. |
| **Απλός χρήστης** | Δεν έχει πρόσβαση σε κάτι εκτός αν τον εντάξετε σε κάποιον οργανισμό. |

#### Επίπεδο οργανισμού

Όταν εντάσσετε κάποιον χρήστη σε έναν οργανισμό, του αποδίδετε έναν από τους παρακάτω ρόλους:

| Ρόλος | Τι μπορεί να κάνει |
| --- | --- |
| **Μέλος (Member)** | Βλέπει τα ιδιωτικά σύνολα δεδομένων του οργανισμού. Δεν μπορεί να τα τροποποιήσει. |
| **Εκδότης (Editor)** | Μπορεί να δημιουργεί, να επεξεργάζεται και να δημοσιεύει σύνολα δεδομένων στον οργανισμό. |
| **Διαχειριστής Οργανισμού (Admin)** | Μπορεί να κάνει ό,τι και ο Εκδότης, αλλά επιπλέον μπορεί να προσθέτει/αφαιρεί μέλη και να αλλάζει ρόλους μέσα στον οργανισμό. |

## Email vs Username — Σημαντική πληροφορία

Κάθε χρήστης στην πλατφόρμα έχει:

- **Email**: Η διεύθυνση ηλεκτρονικού ταχυδρομείου που αντιστοιχεί στον κάθε χρήστη. Είναι **μοναδικό** και **γνωστό εκ των προτέρων**.
- **Username**: Ένα αναγνωριστικό που **αποδίδεται αυτόματα από το σύστημα** κατά την πρώτη σύνδεση του χρήστη. Μπορεί να εντοπιστεί στο προφίλ του χρήστη, αλλά δεν είναι εύκολα προβλέψιμο πριν την πρώτη σύνδεση του χρήστη.

**Συμβουλή**: Στα αρχεία CSV που θα ετοιμάζετε, προτιμήστε να **χρησιμοποιείτε τη στήλη `email`** αντί για `username`. Είναι πιο εύκολο και δεν χρειάζεται να ψάχνετε το username κάθε χρήστη στην πλατφόρμα.

## Πώς λειτουργούν τα αρχεία CSV

Τα CSV (Comma-Separated Values) είναι απλά αρχεία κειμένου όπου κάθε γραμμή είναι μια εγγραφή και οι στήλες χωρίζονται με κόμμα (`,`).

### Παράδειγμα αρχείου CSV

```
email,role
maria@example.gr,editor
giannis@example.gr,member
```

### Πώς δημιουργώ ένα CSV

1. **Κατεβάζοντας το πρότυπο**: Σε κάθε εργαλείο της πλατφόρμας υπάρχει κουμπί για λήψη προτύπου CSV με τις σωστές επικεφαλίδες.
2. **Με Σημειωματάριο (Notepad)**: Γράψτε τις επικεφαλίδες στην πρώτη γραμμή χωρισμένες με κόμμα, και μια εγγραφή ανά γραμμή. Αποθηκεύστε με κατάληξη `.csv`.

## Ποιο εργαλείο χρησιμοποιώ;

| Θέλω να... | Εργαλείο | Πού βρίσκεται | Διαδρομή (URL) |
| --- | --- | --- | --- |
| Δω τους τρέχοντες Κεντρικούς Διαχειριστές | Σελίδα διαχείρισης (Sysadmin config) | Sysadmin → Ρυθμίσεις (Config) | `/ckan-admin` |
| Ορίσω νέους Κεντρικούς Διαχειριστές | Μαζική προαγωγή σε διαχειριστές (Bulk sysadmin promotion) | Sysadmin → Διαχείριση Χρηστών (User management) | `/ckan-admin/users/sysadmin-promote` |
| Αφαιρέσω δικαιώματα Κεντρικού Διαχειριστή | Μαζική προαγωγή σε διαχειριστές (Bulk sysadmin promotion) με "Αφαίρεση όσων δεν είναι στο CSV (Remove missing)" | Sysadmin → Διαχείριση Χρηστών (User management) | `/ckan-admin/users/sysadmin-promote` |
| Δω τα μέλη ενός οργανισμού | Σελίδα μελών οργανισμού (Manage members) | Οργανισμός → Διαχείριση (Manage) → Μέλη (Members) | `/organization/manage_members/<slug-οργανισμού>` |
| Προσθέσω μέλη σε **έναν** οργανισμό | Εισαγωγή από CSV (Import from CSV) | Οργανισμός → Διαχείριση (Manage) → Μέλη (Members) → Εισαγωγή από CSV (Import from CSV) | `/organization/<slug-οργανισμού>/members/import` |
| Ενημερώσω / αφαιρέσω μέλη από **έναν** οργανισμό | Συγχρονισμός από CSV (Sync from CSV) | Οργανισμός → Διαχείριση (Manage) → Μέλη (Members) → Συγχρονισμός από CSV (Sync from CSV) | `/organization/<slug-οργανισμού>/members/sync` |
| Προσθέσω μέλη σε **πολλούς** οργανισμούς μαζί | Μαζική πρόσκληση σε οργανισμούς (Bulk invite to organizations) | Sysadmin → Διαχείριση Χρηστών (User management) | `/ckan-admin/users/bulk-invite` |
| Συγχρονίσω μέλη σε **πολλούς** οργανισμούς μαζί | Μαζικός συγχρονισμός οργανισμών (Bulk org member sync) | Sysadmin → Διαχείριση Χρηστών (User management) | `/ckan-admin/users/bulk-sync` |

> **Σημείωση**: Αντικαταστήστε το `<slug-οργανισμού>` με το αναγνωριστικό του Οργανισμού (π.χ. `diefthinsi-pliroforikis`). Το βρίσκετε στη γραμμή διεύθυνσης (URL) του browser.

## Χρήσιμες σελίδες

### Προβολή τρεχόντων Κεντρικών Διαχειριστών

Στη σελίδα `/ckan-admin` μπορείτε να δείτε τους **τρέχοντες Κεντρικούς Διαχειριστές** του συστήματος. Μπορείτε να φτάσετε εκεί και μέσα από τη σελίδα **Διαχείριση Χρηστών (User management)**, όπου υπάρχει κάρτα που σας παραπέμπει.

### Προβολή μελών Οργανισμού

Στη σελίδα `/organization/manage_members/<slug-οργανισμού>` μπορείτε να δείτε τα **τρέχοντα μέλη** κάθε Οργανισμού. Υπάρχει κουμπί για **λήψη της λίστας μελών σε αρχείο CSV**, χρήσιμο για να ελέγξετε ποιοι είναι ήδη μέλη πριν ετοιμάσετε αρχεία εισαγωγής ή συγχρονισμού.
