# Οδηγός 2: Διαχείριση Μελών Οργανισμού

## Ρόλοι μέσα σε έναν Οργανισμό

Όταν εντάσσετε κάποιον χρήστη σε έναν Οργανισμό, του αποδίδετε έναν ρόλο:

| Ρόλος | Τι μπορεί να κάνει |
| --- | --- |
| **Μέλος (member)** | Βλέπει τα ιδιωτικά σύνολα δεδομένων. Δεν μπορεί να τα τροποποιήσει. |
| **Εκδότης (editor)** | Δημιουργεί, επεξεργάζεται και δημοσιεύει σύνολα δεδομένων. |
| **Διαχειριστής Οργανισμού (admin)** | Ό,τι κάνει ο Εκδότης + προσθέτει/αφαιρεί μέλη και αλλάζει ρόλους στον Οργανισμό. |

---

## Στρατηγική Κεντρικής Διαχείρισης

Αν θέλετε **ο έλεγχος να παραμένει αποκλειστικά στους Κεντρικούς Διαχειριστές (Sysadmin)** και δεν θέλετε να δώσετε σε κάποιον χρήστη τη δυνατότητα να προσθέτει ή αφαιρεί μέλη μόνος του:

**Μη δίνετε τον ρόλο `admin` σε χρήστες στους Οργανισμούς.**

Αντί αυτού, δίνετε μόνο:
- **`editor`** — σε χρήστες που πρέπει να δημιουργούν/επεξεργάζονται datasets
- **`member`** — σε χρήστες που χρειάζεται μόνο να βλέπουν ιδιωτικά datasets

Έτσι, μόνο οι Κεντρικοί Διαχειριστές μπορούν να αλλάξουν τη σύνθεση του κάθε Οργανισμού.

---

## Σημαντικό: Χρησιμοποιείτε email στα CSV

Το **username** κάθε χρήστη αποδίδεται **αυτόματα από το σύστημα** κατά την πρώτη σύνδεσή του. Μπορεί να βρεθεί στο προφίλ του χρήστη, αλλά δεν είναι εύκολα προβλέψιμο.

Το **email** είναι γνωστό και μοναδικό.

**Σε όλα τα CSV αρχεία, χρησιμοποιείτε τη στήλη `email` αντί για `username`.**

---

## Προβολή τρεχόντων μελών Οργανισμού

Πριν ετοιμάσετε αρχεία CSV, μπορεί να θέλετε να δείτε ποιοι είναι ήδη μέλη ενός Οργανισμού.

Στη σελίδα **`/organization/manage_members/<slug-οργανισμού>`** μπορείτε να:
- Δείτε τη **λίστα τρεχόντων μελών** με τους ρόλους τους
- **Κατεβάσετε τη λίστα μελών σε αρχείο CSV** πατώντας το σχετικό κουμπί

Αυτό σας βοηθά να ελέγξετε ποιοι είναι ήδη μέλη πριν ετοιμάσετε τα αρχεία εισαγωγής ή συγχρονισμού.

## Ροή Α: Προσθήκη μελών σε Οργανισμό μέσω CSV (Invite)

Αυτή η ροή σας επιτρέπει να **προσθέσετε νέα μέλη** σε έναν Οργανισμό ανεβάζοντας ένα αρχείο CSV.

### Βήμα 1: Κατεβάστε το πρότυπο CSV και συμπληρώστε

**Μην ξεκινάτε το CSV από το μηδέν.** Στο πλαϊνό πάνελ (sidebar) του εργαλείου εισαγωγής υπάρχει σύνδεσμος για **λήψη προτύπου CSV** με τις σωστές επικεφαλίδες. Κατεβάστε το πρότυπο και συμπληρώστε τα δεδομένα σας.

Το CSV περιέχει δύο στήλες: `email` και `role`.

**Παράδειγμα αρχείου `members.csv`:**

```
email,role
anna.dimitriou@dimos.gr,editor
petros.karagiannis@dimos.gr,editor
sofia.alexiou@dimos.gr,member
```

Αν παραλείψετε τη στήλη `role`, ο ρόλος θα οριστεί αυτόματα σε `member`.

### Βήμα 2: Πλοηγηθείτε στον Οργανισμό

1. Πηγαίνετε στη σελίδα του Οργανισμού στον οποίο θέλετε να προσθέσετε μέλη
2. Πατήστε **"Διαχείριση (Manage)"**
3. Πατήστε **"Μέλη (Members)"**
4. Πατήστε **"Εισαγωγή από CSV (Import from CSV)"**

Εναλλακτικά, μπορείτε να πλοηγηθείτε απευθείας στη διεύθυνση:
`/organization/<slug-οργανισμού>/members/import`

### Βήμα 3: Ανεβάστε το CSV

1. Πατήστε **"Επιλογή αρχείου (Choose file)"** και επιλέξτε το CSV
2. Αφήστε ενεργοποιημένο το **"Dry run (προεπισκόπηση μόνο)"** — εμφανίζει τα αποτελέσματα χωρίς να δημιουργεί καμία πρόσκληση χρήστη σε οργανισμό
3. Πατήστε **"Εισαγωγή"**

### Βήμα 4: Ελέγξτε τα αποτελέσματα

Η πλατφόρμα θα σας δείξει μια αναλυτική αναφορά για κάθε γραμμή:

| Κατάσταση         | Τι σημαίνει                                                                                                                |
|-------------------|----------------------------------------------------------------------------------------------------------------------------|
| **Dry run**       | Η πρόσκληση θα γινόταν, δηλαδή θα εντάσσονταν ως εκκρεμής ο χρήστης στον οργανισμό — δεν εφαρμόστηκε τίποτα (dry-run mode) |
| **OK**            | Ο χρήστης προστέθηκε επιτυχώς ως εκκρεμής (pending)                                                                        |
| **Skip**          | Η γραμμή παραλείφθηκε (π.χ. μη έγκυρο email)                                                                               |
| **Error**         | Παρουσιάστηκε σφάλμα                                                                                                       |

### Βήμα 5 (προαιρετικό): Εφαρμόστε τις αλλαγές

Αν η προεπισκόπηση φαίνεται σωστή:
1. Επιστρέψτε στη φόρμα εισαγωγής
2. **Αποεπιλέξτε** το "Dry run"
3. Ανεβάστε το ίδιο CSV και πατήστε **"Εισαγωγή"** για να δημιουργηθούν οι προσκλήσεις, δηλαδή να ενταχθούν οι χρήστες ως εκκρεμείς στον οργανισμό.

### Βήμα 6: Κατεβάστε τα αποτελέσματα (προαιρετικό)

Πατήστε **"Λήψη CSV (Download CSV)"** για να κατεβάσετε αναλυτική αναφορά.

### Πότε χρησιμοποιώ αυτή τη ροή;

Η ροή Εισαγωγής (Import) αφορά **χρήστες που δεν έχουν συνδεθεί ποτέ** στην πλατφόρμα δεδομένων. Για κάθε χρήστη που περνά επιτυχώς, δημιουργείται αυτόματα ένας **εκκρεμής (pending) λογαριασμός**. Ο χρήστης θα ενεργοποιηθεί αυτόματα κατά την πρώτη σύνδεσή του.

Αν ο χρήστης **έχει ήδη συνδεθεί** στην πλατφόρμα (είναι ήδη καταχωρημένος), χρησιμοποιήστε τη **Ροή Β (Συγχρονισμός)** για να τον εντάξετε στον Οργανισμό.

### Πιθανά σφάλματα κατά την εισαγωγή

Κατά τη διάρκεια αυτής της ροής μπορεί να εμφανιστούν τα παρακάτω μηνύματα σφάλματος:

| Μήνυμα | Τι σημαίνει | Τι κάνετε |
| --- | --- | --- |
| «Αυτό το όνομα σύνδεσης δεν είναι διαθέσιμο.» | Έχει ήδη γίνει πρόσκληση για αυτόν τον χρήστη (υπάρχει ήδη εκκρεμής λογαριασμός) | Χρησιμοποιήστε τη **Ροή Β (Sync)** για να τον εντάξετε στον Οργανισμό |
| «The email address '...' belongs to a registered user.» | Ο χρήστης υπάρχει ήδη στην πλατφόρμα (έχει ήδη συνδεθεί) | Χρησιμοποιήστε τη **Ροή Β (Sync)** για να τον εντάξετε στον Οργανισμό |

Και στις δύο περιπτώσεις, ο χρήστης δεν είναι πλέον "νέος" — απλά ακολουθήστε τη ροή Συγχρονισμού.

## Ροή Β: Συγχρονισμός μελών Οργανισμού (Sync) — Προσθήκη, Ενημέρωση & Αφαίρεση

Αυτή η ροή σας επιτρέπει να **ορίσετε ακριβώς ποιοι πρέπει να είναι μέλη** ενός Οργανισμού. Η πλατφόρμα θα:
- **Προσθέσει** χρήστες που είναι στο CSV αλλά όχι στον Οργανισμό
- **Ενημερώσει** τον ρόλο χρηστών που είναι ήδη μέλη αλλά με διαφορετικό ρόλο
- **Αφαιρέσει** μέλη που δεν είναι στο CSV (αν ενεργοποιήσετε αυτή την επιλογή)

### Βήμα 1: Κατεβάστε το πρότυπο CSV και συμπληρώστε

**Μην ξεκινάτε το CSV από το μηδέν.** Στο πλαϊνό πάνελ (sidebar) του εργαλείου συγχρονισμού υπάρχει σύνδεσμος για **λήψη προτύπου CSV** με τις σωστές επικεφαλίδες. Κατεβάστε το πρότυπο και συμπληρώστε τα δεδομένα σας.

Φτιάξτε ένα CSV με **όλους τους χρήστες που θέλετε να είναι μέλη** του Οργανισμού, μαζί με τον ρόλο τους. Η ροή αυτή αφορά **χρήστες που έχουν ήδη συνδεθεί** στην πλατφόρμα (υπάρχουν ως ενεργοί χρήστες). Για νέους χρήστες που δεν έχουν συνδεθεί ποτέ, χρησιμοποιήστε πρώτα τη **Ροή Α (Import)**.

**Παράδειγμα αρχείου `org_members.csv`:**

```
email,role
anna.dimitriou@dimos.gr,editor
petros.karagiannis@dimos.gr,editor
sofia.alexiou@dimos.gr,member
nikos.papadopoulos@dimos.gr,member
```

Αν κάποιος υπάρχον μέλος **δεν** περιλαμβάνεται στο CSV, θα αφαιρεθεί (αν ενεργοποιήσετε τη σχετική επιλογή).

### Βήμα 2: Πλοηγηθείτε στο εργαλείο

1. Πηγαίνετε στη σελίδα του Οργανισμού
2. Πατήστε **"Διαχείριση (Manage)"** → **"Μέλη (Members)"**
3. Πατήστε **"Συγχρονισμός από CSV (Sync from CSV)"**

Εναλλακτικά, μπορείτε να πλοηγηθείτε απευθείας στη διεύθυνση:
`/organization/<slug-οργανισμού>/members/sync`

### Βήμα 3: Ανεβάστε το CSV

1. Πατήστε **"Επιλογή αρχείου (Choose file)"** και επιλέξτε το αρχείο CSV
2. Αφήστε ενεργοποιημένο το **"Dry-run — προεπισκόπηση αλλαγών (Dry-run)"** — εμφανίζει τις αλλαγές χωρίς να τις εφαρμόσει
3. Επιλέξτε αν θέλετε **"Αφαίρεση μελών που δεν υπάρχουν στο αρχείο (Remove missing)"**:
   - **Ενεργοποιημένο**: Μέλη που δεν είναι στο CSV θα αφαιρεθούν
   - **Απενεργοποιημένο**: Θα γίνουν μόνο προσθήκες και ενημερώσεις ρόλων
4. Πατήστε **"Συνέχεια"**

### Βήμα 4: Ελέγξτε την προεπισκόπηση

Η πλατφόρμα θα σας δείξει ένα αναλυτικό σχέδιο αλλαγών:

| Κατηγορία | Τι σημαίνει |
| --- | --- |
| **Προσθήκες** | Χρήστες που θα ενταχθούν στον Οργανισμό |
| **Αλλαγές ρόλων** | Μέλη που ο ρόλος τους θα αλλάξει (π.χ. από member σε editor) |
| **Χωρίς αλλαγές** | Μέλη που είναι ήδη με τον σωστό ρόλο |
| **Αφαιρέσεις** | Μέλη που θα αφαιρεθούν (δεν είναι στο CSV) |
| **Προστατευμένα** | Λογαριασμοί που δεν μπορούν να αφαιρεθούν (Κεντρικοί Διαχειριστές, εσείς) |
| **Χρήστες που δεν βρέθηκαν** | Email που δεν αντιστοιχούν σε υπάρχοντα χρήστη — χρειάζεται πρώτα Invite |

Αν εμφανιστεί **προειδοποίηση** (warning), σημαίνει ότι πρόκειται να αφαιρεθεί μεγάλο ποσοστό μελών (πάνω από 50%). Ελέγξτε ξανά το CSV σας.

### Βήμα 5: Εφαρμόστε τις αλλαγές

Αν είστε ικανοποιημένοι:
1. Πατήστε **"Εφαρμογή αλλαγών (Apply changes)"** (κόκκινο κουμπί)
2. Η πλατφόρμα θα εμφανίσει σύνοψη: πόσοι προστέθηκαν, πόσοι ενημερώθηκαν, πόσοι αφαιρέθηκαν

### Βήμα 6: Κατεβάστε τα αποτελέσματα (προαιρετικό)

Πατήστε **"Εξαγωγή σχεδίου σε CSV (Export plan as CSV)"** για αναλυτική αναφορά.

### Τι γίνεται αν κάποιος χρήστης δεν υπάρχει στο σύστημα;

Αν κάποιο email δεν αντιστοιχεί σε υπάρχοντα χρήστη, εμφανίζεται στην κατηγορία **"Χρήστες που δεν βρέθηκαν"**. Για αυτούς τους χρήστες, πρέπει να χρησιμοποιήσετε τη **Ροή Α (Import from CSV)** για να τους δημιουργήσετε πρώτα ως εκκρεμείς.

## Ροή Γ: Αφαίρεση συγκεκριμένου μέλους

### Μέθοδος 1: Μέσω Sync (μαζική αφαίρεση)

Αν θέλετε να αφαιρέσετε έναν ή περισσότερους χρήστες:

1. Ετοιμάστε ένα CSV με **όλους τους χρήστες που θέλετε να ΠΑΡΑΜΕΙΝΟΥΝ** στον Οργανισμό
2. Ανεβάστε μέσω **Συγχρονισμός από CSV (Sync from CSV)** με ενεργοποιημένη την επιλογή **"Αφαίρεση μελών που δεν υπάρχουν στο αρχείο (Remove missing)"**
3. Κάντε Preview → ελέγξτε τη λίστα "Αφαιρέσεις"
4. Apply

**Παράδειγμα**: Ο Οργανισμός έχει 4 μέλη (Άννα, Πέτρος, Σοφία, Νίκος). Θέλετε να αφαιρέσετε τον Νίκο. Φτιάξτε CSV μόνο με τους τρεις:

```
email,role
anna.dimitriou@dimos.gr,editor
petros.karagiannis@dimos.gr,editor
sofia.alexiou@dimos.gr,member
```

### Μέθοδος 2: Μέσω του interface (μεμονωμένη αφαίρεση)

Για να αφαιρέσετε **ένα μεμονωμένο μέλος** χωρίς CSV:

1. Πηγαίνετε στη σελίδα του Οργανισμού
2. Πατήστε **"Διαχείριση (Manage)"** → **"Μέλη (Members)"**
3. Βρείτε τον χρήστη στη λίστα
4. Πατήστε το κουμπί αφαίρεσης (κόκκινο **X**) δίπλα στο όνομά του

## Ροή Δ: Μαζική διαχείριση πολλών Οργανισμών (μόνο για Κεντρικούς Διαχειριστές)

Αν χρειάζεται να **προσθέσετε τους ίδιους χρήστες σε πολλούς Οργανισμούς ταυτόχρονα**, μπορείτε να χρησιμοποιήσετε τα εργαλεία μαζικής διαχείρισης από το admin panel.

### Μαζική πρόσκληση σε πολλούς Οργανισμούς (Bulk invite)

Ετοιμάστε ένα CSV με τρεις στήλες: `org`, `email`, `role`.

Η στήλη `org` είναι το αναγνωριστικό (slug) του Οργανισμού — το βρίσκετε στο URL του Οργανισμού. Π.χ. αν ο Οργανισμός βρίσκεται στο `/organization/diefthinsi-pliroforikis`, τότε `org` = `diefthinsi-pliroforikis`.

**Παράδειγμα αρχείου `bulk_invite.csv`:**

```
org,email,role
diefthinsi-pliroforikis,anna.dimitriou@dimos.gr,editor
diefthinsi-pliroforikis,petros.karagiannis@dimos.gr,member
diefthinsi-oikonomikon,anna.dimitriou@dimos.gr,editor
diefthinsi-oikonomikon,maria.papadopoulou@dimos.gr,member
```

Στο πλαϊνό πάνελ (sidebar) του εργαλείου υπάρχει σύνδεσμος για **λήψη προτύπου CSV**.

**Βήματα:**
1. Πηγαίνετε **Sysadmin → Διαχείριση Χρηστών (User management) → Μαζική πρόσκληση σε οργανισμούς (Bulk invite to organizations) → Άνοιγμα (Open)**
2. Ανεβάστε το CSV
3. Ενεργοποιήστε **"Dry run (προεπισκόπηση μόνο)"** για προεπισκόπηση
4. Ελέγξτε τα αποτελέσματα
5. Αν είναι σωστά, ξαναανεβάστε χωρίς dry-run για εφαρμογή

### Μαζικός συγχρονισμός πολλών Οργανισμών (Bulk sync)

Λειτουργεί όπως ο συγχρονισμός μεμονωμένου Οργανισμού, αλλά με επιπλέον στήλη `org`.

**Παράδειγμα αρχείου `bulk_sync.csv`:**

```
org,email,role
diefthinsi-pliroforikis,anna.dimitriou@dimos.gr,editor
diefthinsi-pliroforikis,petros.karagiannis@dimos.gr,member
diefthinsi-oikonomikon,anna.dimitriou@dimos.gr,editor
```

Στο πλαϊνό πάνελ (sidebar) του εργαλείου υπάρχει σύνδεσμος για **λήψη προτύπου CSV**.

**Βήματα:**
1. Πηγαίνετε **Sysadmin → Διαχείριση Χρηστών (User management) → Μαζικός συγχρονισμός οργανισμών (Bulk org member sync) → Άνοιγμα (Open)**
2. Ανεβάστε το CSV
3. Ενεργοποιήστε **"Dry run (προεπισκόπηση μόνο)"** και, αν θέλετε, **"Αφαίρεση μελών που δεν υπάρχουν στο CSV (Remove members missing from CSV)"**
4. Ελέγξτε το σχέδιο ανά Οργανισμό
5. Εφαρμόστε αν είστε ικανοποιημένοι

## Κανόνες ασφαλείας

| Κανόνας | Λεπτομέρειες |
| --- | --- |
| **Κεντρικοί Διαχειριστές δεν αφαιρούνται** | Αν κάποιος είναι Sysadmin, δεν μπορεί να αφαιρεθεί από Οργανισμό μέσω Sync |
| **Ο συνδεδεμένος χρήστης δεν αφαιρείται** | Δεν μπορείτε να αφαιρέσετε τον εαυτό σας |
| **Προειδοποίηση μαζικής αφαίρεσης** | Αν πρόκειται να αφαιρεθεί πάνω από 50% των μελών, εμφανίζεται ειδοποίηση |
| **Dry-run πάντα πρώτα** | Κάνετε πάντα προεπισκόπηση πριν εφαρμόσετε αλλαγές |
| **Προσωρινή αποθήκευση** | Τα αποτελέσματα αποθηκεύονται για 30 λεπτά |

## Συχνές ερωτήσεις

**Ε: Τι γίνεται αν ένα email δεν αντιστοιχεί σε χρήστη;**

Α: Στο Import, δημιουργείται αυτόματα ένας εκκρεμής (pending) λογαριασμός. Στο Sync, εμφανίζεται στη λίστα "Χρήστες που δεν βρέθηκαν" και πρέπει να χρησιμοποιήσετε πρώτα το Import.

**Ε: Μπορώ να χρησιμοποιήσω username αντί για email;**

Α: Ναι, τα CSV δέχονται και στήλη `username`. Όμως, το username αποδίδεται αυτόματα κατά την πρώτη σύνδεση του χρήστη και δεν είναι πάντα εύκολο να το γνωρίζετε. **Προτείνουμε τη χρήση email.**

**Ε: Μπορώ να αλλάξω τον ρόλο ενός υπάρχοντος μέλους;**

Α: Ναι, χρησιμοποιήστε τη ροή Sync. Αν ο χρήστης είναι ήδη μέλος με διαφορετικό ρόλο, η πλατφόρμα θα ενημερώσει τον ρόλο του.

**Ε: Τι κάνω αν θέλω να δώσω `admin` σε κάποιον στον Οργανισμό;**

Α: Μπορείτε, αλλά **προσοχή**: ο Διαχειριστής Οργανισμού μπορεί να προσθέτει/αφαιρεί μέλη μόνος του. Αν θέλετε να κρατήσετε τον κεντρικό έλεγχο, **δώστε μόνο `editor` ή `member`**.

**Ε: Πώς βρίσκω το slug ενός Οργανισμού;**

Α: Κοιτάξτε τη γραμμή διεύθυνσης (URL) του browser. Αν η σελίδα του Οργανισμού είναι `/organization/diefthinsi-pliroforikis`, τότε το slug είναι `diefthinsi-pliroforikis`.

**Ε: Μπορώ να αναιρέσω μια αλλαγή;**

Α: Δεν υπάρχει κουμπί αναίρεσης. Για αυτό χρησιμοποιείτε πάντα **Προεπισκόπηση (Preview/Dry-run)** πριν εφαρμόσετε αλλαγές, και κατεβάζετε τα αποτελέσματα σε CSV για αρχείο. Ξανατρέχοντας τη ροή Συγχρονισμού (Sync) βέβαια μπορείτε να διαμορφώσετε τελικά τα μέλη του οργανισμού στο επιθυμητό σχήμα.
