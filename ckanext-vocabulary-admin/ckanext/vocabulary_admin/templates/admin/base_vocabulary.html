{{ _('Πληροφορίες') }}

Η ενότητα της διαχείρισης λεξιλογίων στοχεύει στο να δίνει μια καθαρή εικόνα στους διαχειριστές του συστήματος των ελεγχόμενων λεξιλογίων που αξιοποιούνται στο σύστημα βάσει των ευρωπαϊκών προτύπων μεταδεδομένων.

Τα λεξιλόγια είναι αντιστοιχισμένα σε συγκεκριμένα πεδία μέσα στο σύστημα.

Σε κάθε πεδίο που έχει συμπληρωθεί με έναν όρο κάποιου λεξιλογίου διατηρείται το URI του συγκεκριμένου όρου. Δεν υπάρχει συσχέτιση με τον ίδιο τον όρο — οπότε θα μπορούσε κάλλιστα κάποιος όρος να διαγραφεί και να αντικατασταθεί με νέο με το ίδιο URI χωρίς να επηρεαστούν οι οντότητες που έχουν τη συγκεκριμένη τιμή.

{{ _('Διαθέσιμες ενέργειες') }}

  • Διαφοροποίηση της σειράς εμφάνισης κάθε όρου στα σημεία του συστήματος όπου εμφανίζεται η λίστα του λεξιλογίου.
  • Διαφοροποίηση ετικετών (Ελληνικά–Αγγλικά) για κάθε όρο, αν η παρούσα μετάφραση δεν κρίνεται ικανοποιητική.
  • Συμπλήρωση περιγραφών σε επίπεδο λεξιλογίου και όρων για τη διατήρηση πρόσθετης πληροφορίας σε διαχειριστικό επίπεδο.
  • Απενεργοποίηση όρου που δεν είναι σε χρήση.
  • Προσθήκη νέου όρου.
